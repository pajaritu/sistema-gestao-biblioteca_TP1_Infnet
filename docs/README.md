## 📌 Sobre o Projeto

Este repositório contém a entrega oficial do **Trabalho Prático 1 (TP1)** da disciplina **Projeto de Bloco: Desenvolvimento Back-End**. 

O projeto consiste na fase inicial de levantamento, modelagem e implementação procedural de um **Sistema de Gestão para Biblioteca Universitária**, cobrindo desde a engenharia de requisitos e modelagem UML até a construção de um programa *standalone* defensivo de console em C# (.NET 10).
